# Changelog

## 0.37 — Initial public release

- C++ firmware for the DSO138 with acquisition, triggering, roll mode, measurements and cursors.
- Adjustable hardware signal generator, negative-rail feedback control and hardware diagnostics.
- UART display mirroring, data export and PC remote control.
- Standalone Windows application with COM-port selection, English interface and demo mode.
- Software entry into the STM32 ROM UART bootloader using PLUS+MINUS at startup.
- Apache-2.0 for vibeDSO work, with project attribution and applicable third-party notices.

See [README](README.md) for features and [validation](docs/VALIDATION.md) for test coverage and limitations.
