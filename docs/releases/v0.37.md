# vibeDSO v0.37 — Initial public release

Custom C++ firmware and a standalone Windows application for the DSO138 oscilloscope with an STM32F103C8 and ILI9341 display.

## Downloads

- **[Firmware ZIP](https://github.com/Chrizzly92/vibeDSO/releases/download/Release/vibeDSO-v0.37-firmware.zip):** flashable HEX and license notices.
- **[Windows ZIP](https://github.com/Chrizzly92/vibeDSO/releases/download/Release/vibeDSO-v0.37-Windows.zip):** standalone desktop EXE and license notices. No Python installation required.
- **[Source ZIP](https://github.com/Chrizzly92/vibeDSO/releases/download/Release/vibeDSO-v0.37-source.zip):** firmware and desktop sources, build tools, tests, documentation and licenses.

## Features

- AUTO, NORMAL and SINGLE triggering, adjustable positions, automatic measurements and A/B cursors.
- Adjustable square-wave generator, peak-preserving roll display, clipping indicators and hardware diagnostics.
- UART display mirroring, sample export and PC remote control.
- ROM UART bootloader entry by holding PLUS and MINUS during startup.

## Getting started

Flash the HEX using an STM32 programmer. Avoid a full-chip erase if you want to retain saved settings and zero calibration. See [firmware update instructions](https://github.com/Chrizzly92/vibeDSO/blob/main/docs/BOOTLOADER.md).

For the desktop application, extract the Windows ZIP, run the EXE and connect a **3.3 V USB-UART adapter** to J5. Select the COM port and **230400 baud**, then click **Connect**. Native USB data is not implemented.

## Pre-release status

Development used a USB-powered board retaining U4. Full operation on an unmodified stock board has not been validated; read the [hardware and USB power notes](https://github.com/Chrizzly92/vibeDSO/blob/main/docs/USB_POWER.md) before flashing.

Build and software/model checks pass. Full physical validation of this firmware build is outstanding. Included calibration values come from one device; they are not a universal calibration. See [validation coverage](https://github.com/Chrizzly92/vibeDSO/blob/main/docs/VALIDATION.md).
